# Xbox控制器驱动层振动控制文档

## 1. 概述

本文档详细说明Xbox控制器在Windows驱动层面的振动控制机制，包括HID报告格式、驱动通信方式以及直接控制方法。

## 2. 驱动架构

### 2.1 驱动层次结构

```
应用层 (Application)
    ↓
XInput API (xinput1_3.dll / xinput9_1_0.dll)
    ↓
HID Class Driver (hidclass.sys)
    ↓
Xbox GIP Driver (xboxgip.sys) - 蓝牙/无线适配器
    ↓
USB HID Driver (hidusb.sys) - USB连接
    ↓
Xbox Controller Driver (xusb22.sys) - 直接USB
    ↓
硬件层 (Xbox Controller Hardware)
```

### 2.2 关键驱动文件

| 驱动文件 | 功能描述 |
|---------|---------|
| `xusb22.sys` | Xbox 360/One USB控制器驱动 |
| `xboxgip.sys` | Xbox无线适配器/蓝牙驱动 |
| `xinputhid.sys` | XInput HID转换层 |
| `hidclass.sys` | Windows HID类驱动 |
| `hidusb.sys` | USB HID设备驱动 |

## 3. 振动控制机制

### 3.1 振动电机类型

Xbox One/Elite控制器包含4个振动电机：

1. **左马达 (Left Motor)** - 低频，大震动
2. **右马达 (Right Motor)** - 高频，小震动
3. **左扳机 (Left Trigger)** - 高频脉冲震动
4. **右扳机 (Right Trigger)** - 高频脉冲震动

### 3.2 HID报告格式

Xbox控制器使用9字节HID输出报告控制振动：

```c
typedef struct {
    BYTE ReportID;      // 0 = USB/2.4G, 3 = 蓝牙
    BYTE MotorMask;     // 0x0F = 所有马达
    BYTE LeftTrigger;   // 0-255
    BYTE RightTrigger;  // 0-255
    BYTE LeftMotor;     // 0-255
    BYTE RightMotor;    // 0-255
    BYTE OnTime;        // 脉冲模式：开启时间
    BYTE OffTime;       // 脉冲模式：关闭时间
    BYTE RepeatCount;   // 脉冲重复次数
} XBOX_VIBRATION_REPORT;
```

### 3.3 脉冲模式配置

- **常亮模式**：`OnTime=255, OffTime=0, RepeatCount=255`
- **脉冲模式**：`OnTime=128, OffTime=128, RepeatCount=255`

## 4. 驱动通信分析

### 4.1 IOCTL代码分析

Windows驱动使用以下IOCTL代码与Xbox驱动通信：

| IOCTL代码 | 用途 | 数据格式 |
|----------|------|---------|
| `0x8000a010` | Microsoft驱动设置状态 | 4字节 (马达强度) |
| `0x002aac08` | Steam驱动设置状态 | 7字节 (包含触发器) |
| `0x8000e00c` | 读取输入状态 | 缓冲区读取 |
| `0x002aec04` | 读取完整状态 | 大缓冲区 |

### 4.2 Steam驱动数据格式

Steam Input使用7字节缓冲区：

```
[0] - 左触发器强度 (0-255)
[1] - 右触发器强度 (0-255)
[2] - 左马达强度 (0-255)
[3] - 右马达强度 (0-255)
[4] - 未知/脉冲参数
[5] - 未知/脉冲参数
[6] - 未知/脉冲参数
```

### 4.3 Microsoft驱动数据格式

标准XInput使用4字节缓冲区：

```
[0] - 未知
[1] - 未知
[2] - 左马达强度 (0-255)
[3] - 右马达强度 (0-255)
```

### 5.2 Xbox控制器VendorID/ProductID

**VendorID**: `0x045E` (Microsoft Corporation)

| ProductID | 控制器型号 |
|----------|-----------|
| `0x02D1` | Xbox One 控制器 |
| `0x02DD` | Xbox One 控制器 (2015) |
| `0x02E0` | Xbox One S 控制器 |
| `0x02E3` | Xbox One Elite 控制器 |
| `0x02EA` | Xbox One S 控制器 (蓝牙) |
| `0x02FD` | Xbox One Elite 2 控制器 |
| `0x02FF` | Xbox 自适应控制器 |
| `0x0B00` | Xbox Series X|S 控制器 |
| `0x0B12` | Xbox Series X|S 控制器 (2021) |

### 5.3 直接振动发送

```cpp
void SendDirectVibration(HANDLE hDevice, 
    float leftMotor, float rightMotor,
    float leftTrigger, float rightTrigger) {
    
    BYTE report[9] = {
        0x00,                    // Report ID
        0x0F,                    // Motor mask
        (BYTE)(leftTrigger * 255),
        (BYTE)(rightTrigger * 255),
        (BYTE)(leftMotor * 255),
        (BYTE)(rightMotor * 255),
        128, 128, 255           // 脉冲参数
    };
    
    DWORD written;
    WriteFile(hDevice, report, 9, &written, NULL);
}
```

## 6. 钩子与拦截

### 6.1 DeviceIoControl钩子

通过MinHook库拦截DeviceIoControl调用：

```cpp
BOOL WINAPI DetourDeviceIoControl(
    HANDLE hDevice,
    DWORD dwIoControlCode,
    LPVOID lpInBuffer,
    DWORD nInBufferSize,
    LPVOID lpOutBuffer,
    DWORD nOutBufferSize,
    LPDWORD lpBytesReturned,
    LPOVERLAPPED lpOverlapped
) {
    // 检查IOCTL代码
    if (dwIoControlCode == 0x002aac08) {
        // Steam驱动 - 修改输入缓冲区
        BYTE* buf = (BYTE*)lpInBuffer;
        int offset = nInBufferSize - 7;
        
        // 注入触发器振动
        buf[offset] = leftTrigger * 255;
        buf[offset+1] = rightTrigger * 255;
        
        // 组合马达振动
        buf[offset+2] = min(buf[offset+2] + leftMotor * 255, 255);
        buf[offset+3] = min(buf[offset+3] + rightMotor * 255, 255);
    }
    
    return real_DeviceIoControl(...);
}
```

### 6.2 优先级控制策略

1. **最高优先级**：直接HID控制（50ms间隔）
2. **中等优先级**：钩子拦截并修改游戏振动
3. **最低优先级**：XInputSetState调用

## 7. 蓝牙/无线适配器差异

### 7.1 2.4G无线适配器

- 使用ReportID = 0
- 支持完整9字节HID报告
- 延迟较低 (~2-4ms)

### 7.2 蓝牙连接

- 使用ReportID = 3
- 缓冲区较短 (nInBufferSize - 7)
- 延迟较高 (~8-16ms)
- 需要处理连接丢失

## 9. 常见问题

### 9.1 振动丢失

可能原因：
- 游戏调用了XInputSetState(0,0) 清除振动
- 驱动缓冲被覆盖
- 蓝牙连接不稳定

解决方案：
- 使用直接HID控制（50ms周期性发送）
- 钩子拦截并忽略游戏的清除指令
- 优先使用2.4G适配器而非蓝牙

### 9.2 权限问题

直接访问HID设备需要管理员权限：

```cpp

}
```
