# gpxinput — 《荒野大镖客 2》扳机震动 mod

给 RDR2 PC 版补上游戏本体从来不给的**扳机震动**。

XInput 的 API 里根本没有「扳机震动」这一路（`XInputSetState` 只能表达两个体感
马达），所以这个 mod 走的是：**冒充 `xinput9_1_0.dll` 被游戏加载** → 完整转发所有
导出到系统原件 → 在震动调用上做加工 → 再用能表达四个电机的出口把值送出去。

出口有两条，互相独立，自动挑可用的那条：

| 出口 | 需要管理员 | 前提 |
|---|---|---|
| `Windows.Gaming.Input` 的 `GamepadVibration`（默认首选） | 不要 | 走手柄驱动栈，原生含左右扳机 |
| HID 输出报告（9 字节） | 要 | 设备必须暴露可写输出报告，很多手柄没有 |
| XInput（两个体感马达） | 不要 | 兜底：扳机内容按 `TrigToBody` 折算到体感 |

只做 HID 那条的后果是「扳机永远不震、体感照常」，看起来像硬件不支持 ——
本项目就踩过这个坑，所以两条都实现了。`proxy/gp_wgi.*` 是前者，
`proxy/gp_hid.*` 是后者。

不注入、不改游戏内存、不改游戏数据、不需要常驻后台进程。

---

## 当前可用范围

**只有「扳机震动」这一路是可用的，其余都还没做完。**

| 功能 | 状态 |
|---|---|
| 开枪 → 扳机脉冲（RT，约 170ms、峰值打满） | ✅ 可用 |
| 按下 LT → 左侧一下短反馈（约 110ms） | ✅ 可用 |
| 扳机输出通道 (`Windows.Gaming.Input`) | ✅ 可用，不需要管理员 |
| 两条出口都不可用时自动折算到体感马达 | ✅ 可用 |
| 武器识别 / 不同枪不同手感 | ❌ 未完成（需要游戏内状态组件，未随包提供） |
| 瞄准持续微震 / 久瞄变抖 | ❌ 未完成（同上） |
| 骑乘辅助震动 | ❌ 判据在 RDR2 上不可靠，默认关闭 |

原因写在发布包 `README.md` 的「已知限制」里：实测 RDR2 的 PC 震动是一条连续
渐变（没有任何跳变），开枪和骑马在波形上完全区分不出来 —— 所以「不同枪不同
手感」这类功能只能靠读游戏内部状态（实现它的只读组件 `asi_rdr2/` 在本仓库里，
但**未完成、不随发布包提供**）。

## 安装

1. 关闭 Steam Input（Steam → 设置 → 控制器 → 对 Xbox 手柄停用 Steam 输入）。
2. 把 `xinput9_1_0.dll` 和 `gpxinput.ini` 复制到 **RDR2 游戏根目录**（与 `RDR2.exe` 同级）。
3. **以管理员身份**启动游戏。管理员是扳机震动的前提：驱动扳机要直写手柄的
   9 字节 HID 报告；没有管理员权限就只剩两个体感马达。

发布包在 [`dist/`](dist/)：`gpxinput_rdr2_haptics_v1.2.0.zip`，含代理 DLL、
配置、`README.md`（完整的安装/配置/限制说明）和 `mod.json`（类型与元数据）。
卸载就是删掉那两个文件，不留任何痕迹。

---

## 从源码构建

```bash
xmake f -p windows -a x64 -m release
xmake
```

打包发布 zip：`python tools/package_rdr2.py`（刷新构建产物 → 按白名单打 zip）。

## 目录

| 路径 | 内容 |
|---|---|
| `proxy/` | 代理本体：导出转发、捕获点、HID 输出、震动合成器（`gp_haptics.*` 是开枪脉冲与辅助震动的地方） |
| `include/` | 共享内存协议（`gp_ipc.h`）、监视段、游戏状态段 |
| `asi_rdr2/` | 游戏内只读状态组件（**未完成，不发包**）。里面记录了怎么从 `ScriptHookRDR2.dll` 取脚本入口 —— 它导出的是 C++ 修饰名，按未修饰名取永远是 NULL |
| `tools/` | 开发工具：离线量脉冲包络、回放录制的震动帧、监视窗口、脚本入口诊断、打包脚本 |
| `dist/` | 发布包 |
| `docs/` | 驱动层振动控制（9 字节 HID 报告格式）等背景资料 |
| `minhook/` | 第三方挂钩库（原样保留，未改动） |

## 边界

- 只做**单机**：不涉及 RDO，不做任何反作弊相关的事。
- 只加工**自己的手柄**收到的震动：不注入游戏、不修改游戏文件与存档。
- 第三方手柄没有扳机电机时，本 mod 会自动退回体感马达，不会失效也不会报错。
